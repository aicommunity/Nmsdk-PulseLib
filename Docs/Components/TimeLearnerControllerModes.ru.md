# TimeLearner: выбор контроллера и владельцев состояния

Этот контракт общий для `NNeuronTimeLearner` и `NNeuronTimeLearnerBranch`.
Описание legacy-фаз на страницах компонентов не является спецификацией V2.
Актуальная область серверной приёмки и оставшиеся ограничения приведены в
[сводке корневого репозитория](../../../../Docs/StructTrain/TimeLearner/ImplementationStatus.ru.md).

## Выбор версии

| Выбор | Поведение |
|---|---|
| Поле `ControllerVersion` отсутствует либо равно1 | Совместимый legacy-контроллер. Старые параметры, фазы и конфигурации продолжают загружаться. |
| `ControllerVersion=2` | Configured native service с явной JSON-декларацией `ControllerConfiguration`, общим bounded search и свежей финальной проверкой. |
| Другие значения или неподдержанная декларация | Отказ с диагностикой; скрытого перехода на другой алгоритм нет. |

Номер контроллера и schema JSON различаются. Base schema1 сохраняет один
замер N0-кандидата;2 задаёт обязательные N0 repeats. Расширения3/4 задают owned
C₀ history/C-search; schema5 является явной recovery-обёрткой над base1..4.
Наличие parser-а не означает приёмку всех физических профилей и сочетаний.
Неизвестные поля, потерянное C₀, неверные типы и несовместимые режимы отвергаются.
См. [configured service](../Analysis/TimeLearnerConfiguredNativeController.ru.md),
[C₀ transport](../Analysis/TimeLearnerCapacitanceStateTransfer.ru.md) и
[recovery/fair-domain scope](../../../../Docs/StructTrain/TimeLearner/FairDomainTraversal.ru.md).

## Параметры и модель V2

ModelSpec и `search` в декларации определяют модель, реальные физические
storage-профили, начальный паттерн, частоту, окна, критерии и конечные бюджеты.
Legacy-свойство с похожим именем не следует считать действующим V2-фактором:
проверяйте владельца и effective readback. Текст JSON не содержит всей обученной
модели, controller checkpoint либо физических потенциалов. Служебный
`ConfiguredModelInitialized` защищает от повторного cold build, но не заменяет
полный import и не доказывает сходимость.

Унаследованные `Experiment`, `LearningAdditionalPattern_1_4` и
`IncrementalLearning` в этих двух TimeLearner остаются пустыми либо
недиспетчеризуемыми методами. Возможности `NNeuronLearner` им не приписываются.
Reserved/no-op свойства допускают загрузку для совместимости, но не могут
служить действующим фактором нового эксперимента.

Общая физика создаётся штатными storage-образами по цепочке канал/синапс →
мембрана → нейрон. Индивидуальные learned Rs/Ns/L и объявленные поправки C
относятся к обученному состоянию. Не исправляйте общую физику записями в детей
на каждом тике или изменением prototype во время жизни экземпляров.

В Classic штатная пачка одновременно попадает на все пути; требуется
сопоставление её волн выбранным входам. Branch выбирает активную точку
подключения, сохраняя весь выдаваемый генератором паттерн. Characterization
одним импульсом является отдельным протоколом, а не заменой обучения пачкой.

Исходная математическая цель V2 — `CapturedPerInput`, fixed referenceN−1.
Предсказание задержки лишь предлагает кандидата: отсутствующий пик не становится
доказательством синхронности. Изменения графа/физики инвалидируют затронутые
измерения; Exact требует свежей проверки каждого входа конкретной модели.
Бюджет, clipping и внешний stop не доказывают недостижимость либо сходимость.

## Lifecycle и управление

Дочерние компоненты рассчитывает обычный scheduler Rdk. Before/After hooks
применяют отложенное изменение на границе пробы и собирают наблюдения;
вложенный `Calculate` модели не требуется. `Build/Calculate/Reset` возвращают
`true`; ошибки описываются состоянием и диагностикой, а не этим bool.

Повторный Build не означает холодное переобучение. Native Reset физического
поддерева для следующей пробы отличается от явного Reset learner и от возврата
к необученной структуре. Исходное rest-state определяется моделью, а не условием
«все выходы равны нулю». Основной проверяемый контур использует единую частоту
дерева; полный multirate scope отдельно не объявляется принятым.

`CalculateMode=0` допускает автоматическое завершение управления;
`CalculateMode=1` сохраняет внешнее управление. Внешнее снятие `IsNeedToTrain`
останавливает управление и не создаёт Exact. В frozen recognition запрос нового
обучения запрещён. `Done`, Need=0, exit0, certificate и качество классификации —
разные результаты. Применимость connected suppliers задаётся контрактом Rdk.

## Train → Test и интерпретация результата

Передавайте полное versioned native learned/stopped package: граф, storage
images, связи, частоту, все learned параметры, references и происхождение
conversion/calibration. Импорт строит модель штатным путём и проверяет effective
semantic identity. Набор Parameters XML overlays не заменяет эту операцию.
Возобновление посреди пробы без полного checkpoint динамики не обещается.

LearnedSoloState и RecognitionState различаются. После conversion/PostTune
старый Exact не переносится автоматически на изменённую модель. Fixed и
подобранный пороги маркируются раздельно; подобранный порог подтверждается
настоящим прогоном. Same-Matrix calibration не является independent Test.
Незавершённый Train допустим для явно диагностической оценки его фактического
состояния; шаблонный нейрон не выдаётся за обученный.

В актуальных отчётах реакции сомы показываются для всех паттернов с реальными
входными импульсами, overview и читаемыми zoom-окнами. Метрики не заменяют
волновые формы. Августовские визуальные4/8–6/8 сохраняют значение в исходном
протоколе; новая очередь экспериментов не возобновляет автоматически сериюD.
