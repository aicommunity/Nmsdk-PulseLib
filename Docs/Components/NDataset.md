# NDataset — датасет из файла

## RU

### Назначение

Загрузка ISI-пачек из файла в `MatrixData` layout `(S*M)×F`. База: [`NDatasetBase`](NDatasetBase.md).

### Формат файла

```text
#NDataset;MaxSpikes=3
class;feat0;feat1
0;0.01;0.05
;-1;0.02
;-1;-1
1;0.00;0.10
;0.10;-1
;-1;-1
```

- Мета `#NDataset;MaxSpikes=M` опциональна (без неё `M=1`).
- Header содержит колонку класса и по одной колонке каждой фичи:
  `class;feat0;feat1` задаёт две фичи. Число `;` = `NumFeatures`.
  Имена колонок не сопоставляются с фичами по имени: действует их позиция.
- На каждый сэмпл — блок из `M` строк: слот0 = `class;v0;...`, слоты 1..M-1 = `;v0;...` (пустое class-поле).
- Реализация также читает последующие слоты без ведущего пустого class-поля:
  `v0;v1;...`. На слот0 метка обязательна по формату.

Прежний пример `feat0;feat1` был неверен для показанных двух значений строки:
существующий parser определял одну фичу и отбрасывал вторую. Исправление примера
не является подтверждением старых файлов либо автоматической заменой их схемы.
Исторические результаты сохраняют фактически использованный layout/commit.

### Lifecycle и пути

`FileName` по умолчанию `input_data.txt`, `UseRelativePathFromConfig=true`,
`UseRelativePathFromWorkDir=false`. Переключатели взаимно отключают друг друга;
когда оба false, `FileName` используется напрямую. Для абсолютного пути
задавать оба флага false и затем имя. `FileName` и флаги запрашивают reload и
делают компонент неготовым; `ReloadDataset=true` явно запрашивает перечитывание.

ABuild читает файл, проверяет форму матриц и через SyncGenerators приводит
число Generator1..N к числу фич. Missing file — idle/retryable, а открытый
файл с распознанной ошибкой формы — ошибка Build в Ready/operation diagnostics. Bool Build
не является признаком успешной загрузки.

Runtime reload — структурная операция владельца до следующего предъявления:
native Build (ABuild → SyncGenerators/Init новых детей) → AfterBuild/Reset → arming. Не
подменять её прямыми присваиваниями матриц после начала импульсов. Новый путь
проверен normal/ASan missing→two features→one feature при2000/20000Hz.
Источники времени/границы проверки: [DatasetClockPlayback](../Analysis/DatasetClockPlayback.ru.md).

### Открытый дефект проверки числовых полей

В текущем parser всё ещё используются atoi/atof: повреждённый токен может
стать нулём, числовой префикс может принять хвост мусора, лишние поля строки
не проверяются. Не считать такой файл валидным лишь по Ready. Планируемый
строгий reader должен проверять всю строку, integer range метки/MaxSpikes,
конечность ISI и точную размерность; отсутствующие значения не достраивать.
Это отдельный открытый пункт, а не уже выполненное исправление алгоритма.

### Favorites

Путь к файлу, `MatrixData`, `MaxSpikesPerFeature`, `Delay`, `Iteration`, `AdvanceSampleAfterBurst`.
