# Семантика истории спайков после Reset

`NPulseLTZoneCommon::OutputPulseTimes` содержит времена событий, а не отсчёты
сигнала. Отсутствие событий задаётся массивом 1×0. Default и Reset должны
очищать размер, а не заменять прежние timestamps нулями: t=0 допустим для
настоящего спайка. Во время расчёта история остаётся ограниченной механизмом
AvgInterval; полный trial runner обязан считывать события на штатных тиках,
а не считать конечный snapshot полной историей длительной пробы.

Изменение не добавляет вложенных lifecycle вызовов, не меняет физику или
порог. NPulseSimpleLTZone сохраняет штатное управление зарегистрированным
static child генератора. Адресный native тест использует storage и настоящий
model scheduler; настоящий onset в t=0 сохраняется, удержание импульса не
дублирует событие, раздельные импульсы дают раздельные timestamps.

Baseline воспроизведён на Elder-1 и M40; fixed gate пока не принят полностью.
Состояние и ограничения: корневой Docs/StructTrain/TimeLearner/SpikeHistoryReset.ru.md.
Наличие этого исправления не является результатом научной оценки распознавания.
