# Области управления ёмкостью: подготовка C-trim

Статус: реализация и fixtures подготовлены в отдельной ветке; серверная
проверка ожидается. C-search в новом контроллере остаётся выключенным.
Документ не заменяет полную постановку обучения и не подтверждает сходимость.

SelectCapacitanceRegion выбирает область по фактическим длинам всех входов:
Classic: dendrite=i+1, segments=[1,L_i]; Branch: dendrite=1,
segments=(L_(i+1),L_i]. Последний опорный вход недоступен для поиска.
Branch требует невозрастающих L. Совпадающие точки подключения дают пустую
область, а не расширение изменения до всего общего кабеля.

MakeCapacitanceRegionRequest сохраняет полную карту активных и dormant
поправок. В выбранной области записывается абсолютный multiplier C/C0.
Повтор запроса не умножает уже изменённую C. Каждая Exc/Inh ёмкость умножается
на собственную неизменяемую C0 штатным native editor, поэтому неоднородность
storage не заменяется общей абсолютной ёмкостью. LT/Soma и прочие области
не меняются. Проверяются пределы масштаба и явный бюджет числа мембран
до разворачивания диапазона, включая граничные целые значения.

Helper не создаёт storage-образы, не вызывает Build/Reset/Calculate и не
удостоверяет существование новых сегментов. Только штатный совместный
native preview/editor может получить эффективную физику новых детей,
проверить C0 и вернуть подтверждённое состояние. Общие прототипы не меняются.

Root fixtures TrainingCapacitanceRegion (7) проверяют геометрию, last-anchor,
идемпотентность, dormant map, пределы и бюджет. NativeCapacitanceRegion (8)
покрывают Classic/Branch, N0/N1, 2000/20000 Гц на настоящих компонентах.
Неодинаковые Exc/Inh C0 заданы storage recipe до создания экземпляров.
Проверяются все фактические дочерние C, полный L/Ns/Rs и все входы до/после
изменения: native burst JSON и недецимированные soma/stimulus CSV.

Эти fixtures подтверждают только область изменения и перенос физики.
Любое изменение C на общем кабеле всё ещё требует консервативной
инвалидации всех затронутых наблюдений и новой финальной проверки всех входов.
Остаются: сопряжённый измеренный поиск L/Ns/Rs/C, fairness бюджета по C,
новые конфигурационные режимы и полная normal/ASan/physics матрица.
