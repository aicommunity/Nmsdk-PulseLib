# Lifecycle и частота структурного обучения

Смена частоты выполняется штатным SetGlobalTimeStep. Для уже инициализированной
физической модели затем вызывается Reset; новое обучение задаёт частоту до Init.
SetGlobalTimeStep самостоятельно не пересчитывает производные величины всех
физических компонентов. В ходе одной frozen пробы частота не меняется.

Регрессионный тест воспроизвёл NPulseSynapse: при 2000 → 20000 Гц с последующим
нативным Reset коэффициенты секреции/диссоциации оставались 2/4 вместо 20/40.
Исправление пересчитывает их в NPulseSynapse::AReset, как это уже делает ABuild.
При неизменной частоте величины не меняются. Это не learner-specific shim и не
изменение общего scheduler. Build/Calculate/Reset bool не используются как статус.

Тесты с реальными Storage и Environment также проверяют Build→Reset для
инициализированного компонента и порядок before/calculate/after, а также fresh
TakeObject и Return/Take образа NSPNeuronGenAsymRmD001C1e9. Образ проверяется без
последующего Default, который стёр бы class parameters. Storage активирует объект;
вручную созданная тестовая компонента должна быть явно активирована до Init.

Проверка коэффициентов не доказывает причинную связь с прежними научными FAIL.
Для этого нужны парные impulse-response и экспериментальные контроли. Old/new
runtime и фактическая частота фиксируются раздельно.

## Rest outputs до первого тика

NConstGenerator::AReset выставляет Output равным Amplitude сразу. Постоянный
источник может рассчитываться после потребителя, поэтому одного update flag
недостаточно: свежий и прогретый экземпляры иначе дают разный первый тик.
NPulseSynapseCommon::AReset сбрасывает Output вместе с PreOutput: публичная
проводимость предыдущей пробы не должна сохраняться до следующего Calculate.

Это модельные состояния: для constant source rest output обычно ненулевой,
для сброшенной секреции синапса проводимость нулевая. Изменение не трогает
uniform physics storage-образов, параметры обучения или computing order.
Сам scheduler не меняется и не выполняет дополнительный Calculate.

Нативные регрессии проверяют outputs сразу после Reset и импульсный отклик
прогретого/нерассчитанного несимметричных графов, входящих в одинаковую пробу
через native Init/Reset. Это исправление может менять первый отклик старых
конфигураций: исторический replay выполняется на зафиксированных старых commits.
Научное влияние на августовское обучение требует отдельного A/B; прежние
наблюдения не отменяются unit-тестом.


## Legacy learner с готовым графом (StructureBuildMode=0)

Этот режим не вызывает BuildStructure и не должен пересоздавать физику.
Однако LoadComponent через UNet заменяет дочерние объекты. Classic и Branch
разрешают именованные Neuron / DatasetMatrix в ABeforeBuild и ABeforeReset.
UNet сначала добавляет дочерний объект с именем образа, а затем LoadComponent
присваивает окончательное сохранённое имя; AAddComponent ещё не гарантирует
возможность узнать роль по этому имени. При N=1 неизменившиеся параметры могут
оставить Ready=true, поэтому одного ABeforeBuild также недостаточно. Это служебные ссылки на фактический граф, а не
восстановление физической модели из parent defaults.

ABuild после legacy ветвей и явная граница Reset подготавливают DendriteNeuronAmplitude и
SomaNeuronAmplitude размером (N+1)×1 через TimeLearner/LegacyReadout.h. Матрицы
правильной формы сохраняются, включая явно загруженное состояние. Загрузка
только Parameters также получает правильные буферы; наличие State-файла не
должно быть обязательным способом выделить память. Одинаковые физические
значения по дереву по-прежнему задаются storage-образами; эта подготовка не
меняет Rs/C, классы, связи или частоту.

BeforeCalculate проверяет инвариант формы до штатного обхода детей. Нарушение
даёт NativeModelEditFailure=legacy_readout_shape_requires_reset_or_build и пропуск
расчёта, без исправляющего resize на тике. Последующий Reset либо реальный Build при Ready=false подготавливает
этот workspace и снимает именно эту диагностику. Обычный вызов Build при
Ready=true остаётся штатным no-op: он не снимает ошибку и не исправляет буфер.
Нельзя использовать самоприсваивания параметров или цепочки пробуждающих
Build вместо штатной загрузки/структурного изменения. Прежнее расширение матриц
Branch внутри Calculate удалено. Native-owned V2 и recognition пути сохраняют
свои самостоятельные lifecycle/ownership ветви.

Runtime-приёмка изменений выполняется отдельно. Исходный d1c3df4cd0749e5869b977fb5e69417400ce1112
дал32/32 отказа расширенного реального XML/readout контроля на normal и ASan: физическая
сома реагирует, а learner cached output остаётся0. Из них12 Parameters-only случаев N>1 имеют два значения вместо N+1;
20 State/N=1 случаев имеют верный размер, но нулевую реакцию learner при
ненулевой реакции сомы. Проверены Parameters-only/State, N1/2/4/6 и обе частоты.
Реальные исправленные прогоны и широкая регрессия проверяются отдельно. Полная матрица
исходного плана и научная эффективность этим контролем не закрываются.

### Warm learner Reset: отдельное исправление public readouts

Адресный baseline root16638b7ad0a822e80ac023a3b97b15a6f756d2e5,
Pulse92241d3/Rdk1699d365 на Elder завершил8 native tests с8 отказами:
физическая Soma.SumPotential после Reset возвращается к начальному rest,
SomaNeuronAmplitude до следующего Calculate сохраняет последний отклик.
Это свежие storage модели Classic/Branch N2/4 при2000/20000Гц;
не hot XML checkpoint и не новая научная selectivity серия.

В AAfterReset обеих legacy topology добавлено чтение уже сброшенных дочерних
мембран и публикация soma/dendrite readouts. Branch rows1..N являются историей
пиков: они и соответствующие private peak/time vectors очищаются отдельно.
Проверка целостности входных векторов/чисел предшествует публикации; ошибка
идёт через NativeEditFailure. Физические C/R/topology и shared prototype не
меняются; вложенного Calculate или дополнительного Reset нет. Все lifecycle
bool остаютсяtrue. Native V2/owned recognition используют прежние ветви.

Реализация ещё ожидает normal/ASan runtime приёмки и адресного повторения
loaded-graph controls. Полный контракт всех controller histories, горячего
checkpoint и остальных физических профилей этим подэтапом не доказан.
