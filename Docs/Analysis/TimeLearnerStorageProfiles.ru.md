# Storage-профили физики TimeLearner

API `Core/TimeLearner/StorageProfiles.h` регистрирует неизменяемые образы до
создания learner. Это часть рефакторинга, а не новая версия алгоритма обучения.
Существующие конфигурации не переводятся на эти образы автоматически.

`RegisterStorageProfile(storage, environment, spec)` строит цепочку канал и
синапс → мембрана → нейрон штатными TakeObject/Build/Init и проверяемой
регистрацией `Rdk::RegisterClassImage`. Возвращаемый список имён упорядочен по
зависимостям. Нельзя изменять опубликованный prototype во время исполнения.
Совпадающее имя с другой физикой вызывает `ClassImageError`; это отдельная
диагностика и не изменение контракта bool Build/Reset/Calculate.

В `NPulseMembrane` добавлены `ExcSynapseClassName` и `InhSynapseClassName`.
Пустое значение использует старый `SynapseClassName`, непустое выбирает образ
своей роли. Новые синапсы получают параметры из соответствующего образа;
сохранившиеся экземпляры сохраняют индивидуальные обученные значения. Замена
класса создаёт и инициализирует новый компонент через штатный Build.

Рецепт явно задаёт C/R/Rrest каналов, Rs/кинетику/PSI синапсов, образы зоны LT
и источников потенциала, частоту и исходный порог. `body` и необязательный
`ltMembrane` имеют независимые C/R/кинетику. Их averaging пока должен совпадать:
этим параметром дерева управляет нейрон. Остальные параметры наследуются от
выбранных базовых образов. Значения по умолчанию описывают объявленный
AsymRmD001C1e9 baseline, а не извлекают физику любого legacy-нейрона.

Для новых образов `UseElementDefaults=false`: общая физика уже находится в
дочерних образах. Индивидуальные learned Rs/C не следует записывать обратно в
prototype или восстанавливать самоприсваиванием параметров на каждом тике.
У роста структуры должен сохраняться обычный native Build без переключения
числа синапсов туда и обратно. Частота задаётся до построения и повторно на
границе завершённого графа перед Init; проверяется частота всех детей.

Поддерживаются зарегистрированные семейства NPulseChannel, NPulseSynapse,
NPulseMembrane, NPulseNeuron, NLTZone и NConstGenerator. Рецепт отклоняет
неверный тип, nonfinite/недопустимые физические значения и neuron mode 0:
готовый неоднородный граф требует полноценного import модели. Новый контур
одной частоты не даёт гарантий для multirate. Смена профиля работающей модели
и произвольные внешние связи также требуют отдельной транзакции модели.

Набор `Test_PulseLib_StorageProfiles.cpp` проверяет роли и legacy fallback,
раздельную физику LT, рост/сжатие, сохранение индивидуальных Rs/C, XML,
частоты 2000/20000 Гц и физический отклик относительно исходного baseline.
Успех этих проверок не доказывает сходимость обучения или распознавание.
Конкретные принятые результаты публикуются в корневом
`Reports/StructTrain/TimeLearner`; до публикации прогон считается незавершённым.

Полный ModelSpec, экспорт определений образов, перенос Train → Test и
сопоставление всех исторических профилей остаются следующими задачами.
Process-local descriptor registry нельзя использовать как переносимый
научный fingerprint или checkpoint физической динамики.
