NativeTrainingService явно направляет protocol4 в NativeCompositeTrainingAttempt. Один запрос reference/search/final — одна N+2 группа. Только первая подготовка группы вооружает typed consumer; сырые Recorder6 пакеты сохраняются и передаются evidence sink на каждой границе, но не потребляются контроллером как самостоятельные измерения. Семейство цели содержит реальные начальные native snapshot, dataset, identity, storage closure, source profile и существующий C0, если он есть. Reset отзывает живой lease, сохраняя цель/ссылки/исходное семейство. Следующий owned restart получает новый lifecycle observation и live generation без пересъёмки обученной структуры в качестве исходной цели. Default, pool lifecycle и явный retarget уничтожают семейство. После разрешённого изменения параметров обновляется живой lease и epoch, а clocks/counters попытки продолжаются. C-trim Off не требует C0; никакой единичный baseline не создаётся.

Перед потреблением закрытой группы повторно проверяются actualNeed, lifecycle, текущая модель, source/storage/C0 и реальный wall/model deadline. Остановка не списывается как invalid observation. Финальная проверка использует свежие группы всех N входов; scalar residual math и configured tolerances прежние. Новый accepted-composite counter фиксирует реальное принятие typed scalar, а не выводится из отсутствия ошибок или конечного статуса.
