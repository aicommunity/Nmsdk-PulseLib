# Self-contained native composite archive1 и certificate2 encoder

Source-prepared implementation; C++ сборки/численные тесты локально не запускались. Runtime acceptance pending. Это следующий конечный source chunk после service/cold declarations; package5 physical import, portable scalar/final replay и Console Train→Test остаются обязательными следующими изменениями. Новый режим не включён в defaults/общие experiments.

NativeCompositeTrainingEvidence.{h,cpp} сохраняет реальные N+2 raw callbacks/packets, canonical CSV, method/window/context/geometry policies, source/model/reset/epoch bindings, actual source/ISI readback и существующий C0. Все primary bytes встроены в archive; optional resolver обязан вернуть те же bytes для каждого логического пути. Никакого fallback при missing mirror, лишних blobs, повторных/case-colliding paths, неизвестных fields/types, bool counts или неканонического CSV. Счётчики primary bytes складывают логические ссылки, без вычитания одинаковых SHA.

Decoder создаёт закрытый DecodedNativeCompositeArchive, а не live authority. Полные группы повторно проходят production matched portable codec1 и новый native basin selector; actual maximum/relative arrival/proof проверяются заново. Source initial dataset snapshot дополнительно проверяется по реальным MatrixData/dimensions/Generator1 parameters. Partial records сохраняются без восстановления неизвестных reset/instance context, не попадают в reference/final/consumed sets и не объявляются complete composites. Причина неполной closure не доказывается whitelist ошибок.

Один shared semantic proof helper используется живым NativeAttempt и portable replay. Его вход — const view, чтобы не копировать полные N+2 waveform только ради hash. File paths отсутствуют в proof, тогда как live attempt/run/trial/group identities и все policy limits сохранены. artifact_document_sha256 канонически связывает весь документ вместе с paths. SourceOrigin обозначает immutable target family, не hash фактически обученной модели.

Actual source boundary проверяется отдельно от neuron-only identity: внешний Dataset/Generator profile может измениться при том же neuron boundary-port hash. NativeAttempt теперь сравнивает восстановленную фактическую dataset semantic model с initial snapshot перед mint/consume/warm restart. Это не per-tick repair и не изменение параметров. Два новых native controls меняют source amplitude между close и consume и требуют отсутствия нового принятого final/certificate.

Certificate2 encoder публикует только закрытый TrainingCertificate, уже вычисленный общим FinalVerification scalar math. Он сохраняет source family, reference/final semantic proof IDs, прежние tolerances/residuals и отдельный semantic_certificate_id. Старый certificate1 wire/math не меняется. Сам encoder не даёт new Train authority и не является package5 importer.

Под TIMELEARNER_COMPOSITE_OUTPUT реальные service fixtures пишут шесть self-contained bundles: classic-service, branch-service, classic-partial, branch-C0, classic-warm, branch-ambiguous. В каждом index/record sidecars, CSV всех captured soma и actual stimulus, initial cold6, actual runtime plan, actual after-model/dataset snapshots/inputs/C0 и реальные reference/final residuals. Первый completed source каждого topology выполнен один раз на процесс; adversarial cases повторно анализируют его неизменные bytes, не синтезируют peaks. Missing/ambiguous/partial не превращаются в success.
