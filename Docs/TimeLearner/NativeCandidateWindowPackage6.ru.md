## Wire и граница

`NativeCandidateWindowStateFactory` — отдельная explicit ветвь рядом со старой
`NativeCompositeStateFactory`. Package6 имеет ТОЧНО прежний top-level keyset
package5, но принимает только комбинацию:

| Поле | Версия/смысл |
|---|---|
| schema_version | 6 |
| configuration | original cold7, common policy2/candidate policy1, initial P0/windows |
| protocol | 5, immutable reference window/mapping + candidate-window contract2 |
| runtime_plan | 2, full protocol_binding и ACTUAL current attempt/search/tolerances/caps |
| measurement_archive | 2, полная retained history, original refs, current selected latest final |
| certificate | 3 для completed; null для stopped/partial |
| neuron / dataset | complete native physical archives, actual current graph / restored full source |
| capacitance_state | actual owned C0+scales или null при Off без C0 |

Остальные обязательные поля прежние: kind/dynamic_checkpoint/state_kind,
implementation/controller/calculate/structure modes, trained_inputs,
model_revision/model_epoch/session_attempt/training_outcome/reason,
capture_revision/capture_epoch/reference_complete и sha256. Unknown/mixed версии
не получают aliases; old5 по-прежнему означает cold6/protocol4/runtime1/archive1/cert2.
Old factory Export/Prepare/Restore bodies не переписаны; общий Metadata helper
только обобщён по закрытому proof type с прежним телом и полями.

Export6 требует настоящий service Finished, session>0, version2, legal modes,
actual owner neuron/dataset/storage, current semantic identity и native parameter
readback. Source declaration, original creation policy, dataset MatrixData/profile
и restored full mask сверяются с immutable original family. Archive2 encoder и
strict decoder replay первичных данных предшествуют portable proof.

**Completed** определяется наличием настоящего service certificate и его
Outcome Exact/SearchUnresolved, затем проверяется полное равенство live cert3
с новым portable residual proof и actual graph/epoch/tolerances. **Stopped**
имеет terminal outcome/reason и diagnostic/null certificate, даже если все
последние actual final observations математически Exact. Сам mathematical
certificate не меняет service outcome. Mid-probe/active boundary не экспортируется.

## Prepare и import

Prepare6 строго проверяет keysets/digests, cold7/protocol5 equivalence исходного
target/method, runtime2 binding, archive2/current attempt/counters/caps и cert3.
Он импортирует complete class definitions, фактический dataset, ОТДЕЛЬНО original
initial native snapshot и current physical graph. Initial/current full semantic
readback и actual input parameters проверяются; current graph не строится из
начальных L/Ns/Rs и original targets не recapture из trained structure.
Storage image fingerprint и original C0 origin не заменяются текущими defaults.

Immutable original cold7/search/P0 и current runtime2 не приравниваются. Warm
run/search/tolerances/time/primary caps/model/epoch могут отличаться от initial
planning fields. С initial cold7 совпадает именно неизменённый protocol5
target/method/reference windows/candidate policy. Нормализация сохраняет текущий
native Start5 ownership predicate; historical records сохраняют свои caps.
Current records проверяются по actual current runtime, вся retained prefix
история — существующим strict archive2 ledger validator. Нулевая current attempt
не выдаётся за новые измерения, её initial boundary совпадает с текущим graph.

Restore ставит service Finished/DATA, original references/closed window references,
source/family/initial config/history/selected IDs, counters и current epoch.
Не восстанавливаются actor, raw executor, search traversal, prepared values,
callback addresses или owner-control token. `IsNeedToTrain=false` при штатном
InstallNativeLearnedState. Последующий native Start5 использует existing imported
archive factory и создаёт НОВУЮ live lease с actual fresh boundary checks.
Partial capture сохраняет original-model constraint; measured prefix не становится
consumed allN set. Reset/warm сохраняет complete original family, Default/retarget
по-прежнему имеет отдельный lifecycle.

C-trim Off не требует фиктивного C0/нового C-property guard. Если original C0
существует, проверяются baseline model/images/map и actual applied scales; удалить
его или recapture из trained graph нельзя. Асимметрия excitation/inhibition в
тестах объявляется REGISTERED STORAGE IMAGES до native construction.

Package content hashes и semantic proof IDs не являются подписью исполнения.
Prepare проверяет совместимость DATA/математики/physical import, не доказывает
исторический процесс или отсутствие согласованного переписывания всех публичных
metadata. Existing execution/artifact provenance должен связывать именно bytes
фактического export. Никакого portable права вызвать live Consume из этих bytes нет.

Адресный actual test `CoherentTerminalRewriteNeedsOriginalExportBinding` начинает
с настоящего ExternalStop после last accepted final: исходный Export6 остаётся
diagnostic/null. Затем test согласованно меняет kind/outcome/cert и matching
model metadata с пересчётом hashes при НЕИЗМЕННОМ waveform/graph. Prepare6
принимает математически совместимую DATA в Finished без live authority; тест
НЕ выдаёт это за producer success. Changed package semantic hash и exact bytes
отличаются от original export. Новый completed classification обязан сохранить
существующую pipeline проверку original `execution.package_sha256`, artifact
file hashes/source-case linkage; hash только переписанного package её не заменяет.
Сейчас Python/Console package6 join ещё не поддержан и должен fail closed.
Это явный limit portable native format, не self-contained доказательство Stop.

## Проверки и остаток

Root `NativeCandidateWindowPackage.*` содержит реальные configured cold7
Environment/storage/scheduler cases: Classic/Branch physical roundtrip,
storage-owned asymmetric child physics/C0, imported warm с иными current caps/tols,
actual owned growth, raw partial, staged reference prefix, default `.02` non-Exact,
external stop после complete Exact final, foreign source/current initial-template
substitution и rehashed/mixed-version claims. Positive `.2` N2 cases — engineering
format/plumbing, не научное доказательство `.02`/N4 convergence.
Actual CSV/full/omit/repeat/source/current snapshots сохраняются producer writer.

Это НЕ summary7/Console4/Python package6/CLI Train→Test activation: соответствующие
старые guards остаются; Native public Export/Import6 — отдельный завершённый
source-компонент. Следующий подэтап интегрирует именно существующие summary,
Console, independent readers и managed pipeline. N=1 multi-peak/contract5,
heterogeneous WITHIN-bank Rs DATA capability и научный N4 matrix здесь не закрыты.
Локально выполнены только Git/source checks; compilation/native numerical tests
этого блока выполняются отдельно на серверах после текущего frozen48.
