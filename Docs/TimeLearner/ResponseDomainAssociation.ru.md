# Диагностический граф областей отклика

`ResponseDomainAssociation` — отдельный versioned контракт поверх
`MeasuredResponse`. Он проверяет гипотезы соответствия измеренных вершин
областям импульсов. Его schema1 не является schema1 `ProbeObservation`.
Действующие schemas1–6, references и certificates не меняются.

Вход содержит run/trial/sample ID, hash паттерна, модель и протокол, actual
stimulus timestamps, полное окно и период измерений, baseline и отсчёты всех
измеряемых каналов. Spec связывает модель/протокол/паттерн, ожидаемые ID и
ровно одну область для каждой пары «физический канал × предъявленный импульс».
Нельзя убрать область конкурента, чтобы получить однозначное соответствие.

Каждый канал проходит общий production extractor. После проверки полноты,
чисел, timestamp order/gaps и identity для каждой области выбирается её
единственный наибольший измеренный максимум. Меньшие экстремумы сохраняются.
Раздельные одинаковые максимумы дают Ambiguous; непрерывное плато остаётся
одной вершиной с двумя timestamps. Обрезанный максимум не принимается.

Если другую область того же канала пересекает часть выбранного плато после
actual onset её импульса, вершина считается общей. Учитывается также импульс,
пришедший внутри плато, а не только до его начала. На разных физических
каналах совпадение времени само по себе не создаёт конкуренции. Отсутствие
пика постороннего импульса не запрещает локальную гипотезу активного.

Результаты: Hypothesis, NoCandidate, Ambiguous, Clipped, Incomplete,
OutsideApplicability, InvalidSpecification, InvalidSamples. NoCandidate
означает отсутствие кандидата в объявленной области, а не отсутствие
физической реакции или PhysicalInfeasible. При неприменимости/неоднозначности
измеренные признаки сохраняются. Для уникального измеренного максимума
сохраняются signed offsets начала/конца плато от actual stimulus; отрицательный
offset не заменяется прогнозом. Это временные разности, не доказанные задержки.

**Hypothesis не подтверждает происхождение отклика.** Задержанная волна
предыдущего импульса может оказаться единственным максимумом ошибочной области
следующего. Этот counterexample включён в тесты. Method ID фиксирован:
`declared-response-domains-diagnostic-v1`; `TrainingCertificateEligible()`
всегда false. Тип не преобразуется в ProbeObservation/CapturedReferences.
Интеграция в Train требует отдельного метода applicability/evidence, новой
версии контрактов и серверной приёмки. Общий максимум пачки не подставляется
вместо максимума закреплённого импульса.

Окна не являются доказанными физическими границами. Здесь нет предположения
о линейности/суперпозиции, автоматического выделения вклада импульса или
применения EstDelayPerSeg как доказательства. Utility не меняет компоненты,
storage, структуру, параметры или scheduler и не рассчитывает модель.
