# Train5 typed core / certificate3: source-подэтап S3-A

Статус: implementation source preparation, не runtime acceptance. Перед ним отдельный mechanical pin `823d47d` выделил numeric preflight; old97 A/B остаётся независимым gate. Default ControllerVersion/recommendations, service dispatch, cold7/learned6/summary7/Console4 не активируются этим подэтапом. Prototype influence-exclusive v1 не становится Train criterion.

## Закрытые исходные данные

`CandidateWindowReferenceSet` дополнен immutable typed protocol, original model revision/epoch и ordered target raw potentials. Значения создаются только прежними native allN release и strict archive2 portable factory из реальных source/peak/primary; public constructor/valid flag нет. Read-only proof/group IDs не mint authority. Private `CandidateWindowCoreValidation.h` без Qt/Rdk сверяет COMPLETE CapturedReferences с этим набором: protocol, source/family, original model/epoch, inputs, ordered groups/proofs и реальные raw targets.

Staged reference — измеренная diagnostic опора, ещё НЕ consumed в полный набор. Все N selected records получают consumed/Need-at-consume только после полного release. Fallible copy готового closed set выполняется до nonthrowing flag commit, чтобы не продвинуть prefix при allocation failure. Partial family не ослабляется.

## Separate typed consumers

Новые overloads `BoundedTrainingSession(refs,closedRefs,...)`, `FinalVerificationSession(refs,closedRefs,...)` и `Arm/Consume/RejectCandidateWindow` принимают только protocol5/contract2. Старые raw/ArmComposite/ConsumeComposite5 продолжают отказывать. Новый `ValidateCandidateWindowTrainingConfiguration` — только numeric/protocol preflight перед capture, его успех не даёт measurement authority.

Existing common scalar acceptance/Finish equations, ranking, candidate traversal, fixed N−1 anchor и N0 repeats не переписаны. C0Off не требует baseline; N1 normalization сохраняет прежние domain responsibilities. Здесь native fixed-parameter standalone N1 fixtures НЕ объявляются service/domain integration. N=1 input legacy path остаётся прежним; новый N+2 method требует N≥2, single-input multi-peak пункт полного плана остаётся открытым.

Prepared имеет отдельный private `RequireCandidateWindow`, общий lease/request guard и factory-owned `requireCandidateWindowAdmission`. Pure core не устанавливает callback, не вызывает Rdk/JSON/native reset и не восстанавливает его из portable данных. Native factory проверяет expected complete refs, frozen prequeue identity, фактические graph instances/effective-or-base model context, source/family/C0, затем снова выводит full binding/policy proposal. Need=false, lifecycle/rebuild/model/source mismatch не принимаются по cached caller strings. Real attempt/group deadlines проверяются до/после admission replay; задержка после close не превращается в бесплатный consume.

Перед завершением allN final ранее accepted private preparations ещё раз проверяются на ту же актуальную graph/source/lease. Их собственные deadlines были проверены при consume; последующие группы не считаются продлением старого измерения. Controlled edits по-прежнему требуют controller Applied/Invalidate и нового epoch; Branch invalidate очищает все inputs. Invisible same-node direct-value ABA без штатного owned edit notification не объявляется поддержанным.

## Certificate3 и явная граница portability

Certificate3 сохраняет actual raw/arrival/plateau math и прежние tolerances. Source/family check в Matches действует и для5; Recognition не наследует OriginalExact. Поля cert2 дополнены `protocol_binding`, `current_attempt_id`, `final_run_id`, ordered `final_window_recipe_ids`, `final_measurement_instance_ids`; все N final proofs/recipes/instances обязательны. Actual semantic attempt/final run берутся из frozen proposal, не из filenames/live pointers. Serializer пересчитывает полный protocol hash и semantic certificate ID.

Old cert1/2 paths сохраняются. Until separate codecs/service composition, old learned/summary entry points явно отвергают protocol5 (`requires_package6`/`requires_summary7`) вместо записи под старой scalar schema. Portable certificate3 replay/package6 import остаются следующим source-подэтапом; archive2 decoder/reference replay не создаёт live lease. Core certificate companion в fixtures не является completed portable package6: actor measurement archive пока не содержит service accepted final selection.

## Проверки и evidence scope

24 `NativeCandidateWindowTrainingCore.*` source-prepared cases используют actual storage/neuron/dataset, N+2 production groups и настоящий внешний scheduler. Проверяют N0 repeats, fixed N1 normalization, C0Off/boundC0, 20k allN final, default sync `.02` non-Exact, actual pattern-relative timing при разных ABS begins, legacy/raw admission refusal, reference/search/old-sweep/family mismatch, Need setter/direct/connected, owner Reset/Default, real structural/C0 edit и same-hash rebuild, actual-clock delayed consume budget и Branch allN invalidation. Assertions не конструируют fictitious peaks/packets.

Все реально выполненные full/omit/repeat groups сохраняют primary CSV со всеми somas+actual source, actual native packets/spec/context/proposal/binding и before/after models. `certificate3.json`/`core-search.json` явно отмечены `typed_core_before_service_package6`; inactive native-service math не подменяет core math. Engineering Exact fixtures используют ЯВНО `.2`, default `.02` имеет отдельный OutsideTolerance control; scientific convergence этим не утверждается. Local compile/syntax-only/numerical runs и server cache updates не выполнялись.
