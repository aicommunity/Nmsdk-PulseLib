# Private native owner control lifetime

Статус: source implementation для отдельного server gate, без runtime acceptance. Base Pulse `800f92ae1f9e0133cefc0ccfe36abc3d8c99727f`; unfixed actual-native source reproducer Root `f74b9fbf9ece38668396c21fa569d688f595bb05` остаётся неизменённым. Никаких local C++ builds/numerics или server/cache updates не выполнялось. Full248 и S3-B470 остаются самостоятельными gates; package6/CLI/defaults не включены.

`NativeTrainingService` хранит один private shared empty identity token; actor Bind получает weak observation в fallible native construction. Никакой JSON/config/proof/counter не создаёт такой token. Reset/interrupt и успешный Start3/4/5 commit вызывают allocation-free `reset()`. Finished ничего не mint-ит/не восстанавливает. Saved Record/archive/DATA decoder не зависят от token и остаются читаемыми после отзыва.

Общий actor guard сначала проверяет !cancelled и текущий Rdk owner lifecycle, затем actual Need. Exact `service.composite.get()==this` разрешён для prepublication/owned restart/edit; он не обходит эти проверки и не оживляет прежний revoked lease. Иначе service должен быть не Active, weak lock обязательно nonnull И равен CURRENT service token. Оба null запрещены. Новый manual actor после Finished получает current token; старый actor не обновляет свой observation.

CheckClock/CheckBoundary, все три private live lease factories (initial/restart/edit) и adapter.queue после beforeNativeQueue callback используют один guard. Поэтому open Arm и closed Consume не обходят takeover. Executor generation checks take/cancel и все прежние `attempt/compositeGeneration` increments/order/math сохранены. Raw/notification/sink callback bodies остаются прежними; CaptureCompositeInterrupt имеет только новый начальный allocation-free invalidation. Никаких nested Calculate, component Reset/Build calls, parameter writes, per-tick physics repairs или изменений tolerance/target/assignment нет.

ResetControl инвалидирует token даже при отсутствии stored composite. Поэтому конкретный Begin, реально сбросивший executor, отзывает old manual authority и при последующем InvalidModel до constructor/commit. Early Begin refusal ДО executor Reset не добавляет takeover. Portable imported prepared service не содержит live token; move replacement уничтожает старую control identity, не воссоздавая её из sessions. Per-probe child Reset, свои N+2 next groups и штатный owned edit не инвалидируют service token; initial family/P0/C0/raw targets остаются immutable.

Новый reason `native_training_owner_control_replaced` означает stale live authority, а не ошибку physics/measurement/DATA. При actual Need=false сохраняется `CompositeTrainingStopped`/ExternalStop. Это не обещание наблюдать невидимый direct-value ABA или общая политика одновременных manual actors. Return values Build/Calculate/Reset не используются как ошибки.

Для приёмки требуются отдельно: unfixed negative outcomes; repaired f74 4 controls; failed Begin без stored composite; actual scalar3/fixed4 takeover; NEW manual-after-Finished; own next-group/edit/warm/open Arm/callback reentry; old full248 and source470/lifecycle/math A-B. Сходимость, package6/summary7, independent primary replay и полный Train→Test этим source patch не объявлены завершёнными.

Source follow-up после353: public `InterruptComposite` тоже инвалидирует token ДО своего `if(!composite)return`. Ранее353 invalidation стояло лишь в вызываемом CaptureCompositeInterrupt, до которого этот ранний выход не доходил. Capture сохраняет свой guard для прямого StopComposite; повторный reset пустого token allocation-free и не меняет поколения/callback order. NativeLearnerLifecycle routing только protocol4/5 не расширяется: обычные Reset/Default дополнительно защищены ResetControl/Rdk lifecycle, здесь исправляется низкоуровневый public interrupt contract. Runtime coverage этого follow-up требует отдельного реального no-stored-composite control, не выводится из source review.
