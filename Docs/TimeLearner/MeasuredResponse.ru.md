# Измеренные признаки отклика

`Core/TimeLearner/MeasuredResponse.h` отделяет извлечение измеренных признаков
от назначения импульсам и выбора пика. `ExtractMeasuredResponse` принимает
отсчёты одного физического канала, его явный rest baseline и минимальную
амплитуду. Возвращает все положительные внутренние максимумы с точными
индексами/временами начала и конца плато; общий максимум; число раздельных
внутренних максимумов той же высоты; два независимых признака clipping.

`globalMaximumClipped` относится к выбранному глобальному максимуму.
`boundaryResponseClipped` обнаруживает положительный продолжающийся отклик на
границе даже при более высоком внутреннем максимуме. Внутренние измеренные
вершины сохраняются и при clipping. Ни один из этих флагов не назначает вершину
импульсу. Равные раздельные максимумы остаются раздельными; непрерывное плато
является одним максимумом. Предсказанные задержки и интерполяция не применяются.

Функция проверяет finite всех отсчётов и разностей с baseline, строгое
возрастание времён, параметры и минимальный размер записи. При повреждении
не возвращает частично собранные признаки. Valid здесь означает корректность
представленных отсчётов: полноту объявленного окна, допустимый sampling gap,
model revision и actual stimulus timestamps проверяет вызывающий recorder.

Оконное измерение и OrderedWholeBurst в `ProbeObservation.cpp` используют один
production extractor. Это механическое выделение общей измерительной части:
schemas1–6, early returns Missing/Clipped, legacy window ambiguity, число волн,
назначение по порядку и SingleImpulseMaximum сохраняют прежний смысл.
Научную политику назначения следует менять отдельным commit и контрактом.

Largest maximum полной пачки не становится максимумом закреплённого импульса.
Сам extractor не выдаёт ни CapturedReferences, ни TrainingCertificate. Он не
обходит native scheduler и не изменяет физику, storage или lifecycle Rdk.

Серверная приёмка требует существующих recorder/verification/subset unit tests,
новых feature cases и интеграционной проверки реальных native/storage путей.
До её завершения изменение остаётся кандидатом.
